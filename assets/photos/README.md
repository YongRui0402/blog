# 喘息照

把**你自己拍的**照片丟進這個目錄(`.jpg` / `.jpeg` / `.png` / `.webp`)。

## 它們會怎麼被用

長文章(3 個以上 `##` 段落)每隔兩段會自動插入一張,給讀者一個
視覺停頓去消化剛才那一段。**選圖是決定性的** —— 同一篇每次建置拿到同一張,
不會每次 deploy 都在跳。

單篇不想要:front matter 加 `no_photos: true`。

## 建議

- **橫幅構圖**,直式在文章中間會佔掉整個螢幕
- **不要有可辨識的地標或門牌** —— 對外身分是 BDGG,照片會洩漏你住哪
- 長邊 ≥1600px(會自動產 640/1100/1600 三種尺寸並轉 webp)
- 檔名隨意,不影響選圖

## 為什麼不用圖庫

自己拍的照片授權乾淨、有個人感,而且不會和別人的部落格撞圖 ——
Unsplash 那幾張熱門圖在技術部落格上出現的頻率高到會讓人出戲。
